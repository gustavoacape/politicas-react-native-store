# POLÍTICA DE PRIVACIDADE

## 1. INTRODUÇÃO

Esta Política de Privacidade descreve como o aplicativo **store-react-native** (“Aplicativo”) coleta, utiliza, armazena e protege os dados pessoais dos usuários.

Ao utilizar o Aplicativo, o usuário concorda com as práticas descritas nesta Política.

---

## 2. DADOS COLETADOS

O Aplicativo poderá coletar os seguintes dados pessoais:

### 2.1 Informações fornecidas pelo usuário

* Nome
* Endereço de e-mail
* Número de telefone (quando informado)
* Identificador do usuário (User ID)

### 2.2 Dados coletados automaticamente

* Informações de uso do aplicativo
* Produtos visualizados nas vitrines
* Itens marcados como favoritos
* Interações com funcionalidades
* Dados técnicos do dispositivo (como identificadores e informações de uso)

---

## 3. FINALIDADE DA COLETA DE DADOS

Os dados coletados são utilizados para:

* Permitir autenticação e acesso à conta do usuário
* Exibir produtos e vitrines
* Salvar e gerenciar itens favoritos
* Facilitar o contato com vendedores via WhatsApp
* Melhorar a experiência do usuário
* Monitorar desempenho e estabilidade do aplicativo

---

## 4. COMPARTILHAMENTO DE DADOS

Os dados poderão ser compartilhados com serviços terceiros essenciais para o funcionamento do Aplicativo, incluindo:

* Supabase (armazenamento e autenticação)
* Firebase (analytics, desempenho e estabilidade)

Além disso:

* Ao utilizar a funcionalidade de contato via WhatsApp, o usuário será redirecionado para o WhatsApp, sujeito às suas próprias políticas.

Os dados não serão vendidos ou compartilhados para fins comerciais.

---

## 5. ARMAZENAMENTO E SEGURANÇA

Os dados são armazenados em ambientes seguros e protegidos por medidas técnicas adequadas.

As informações são transmitidas de forma criptografada.

---

## 6. RETENÇÃO DE DADOS

Os dados pessoais serão armazenados apenas pelo tempo necessário para cumprir as finalidades descritas nesta Política.

Dados poderão ser mantidos enquanto a conta estiver ativa.

Após solicitação de exclusão, os dados serão removidos, exceto quando houver obrigação legal de retenção.

---

## 7. DIREITOS DO USUÁRIO

Nos termos da Lei Geral de Proteção de Dados, o usuário pode:

* Solicitar acesso aos seus dados
* Solicitar correção de dados
* Solicitar exclusão
* Obter informações sobre o uso dos dados

---

## 8. EXCLUSÃO DE DADOS

O usuário poderá solicitar a exclusão de sua conta e dos dados associados.

A solicitação pode ser realizada através de:

Os dados serão excluídos em prazo razoável, salvo obrigação legal.

---

## 9. SERVIÇOS DE TERCEIROS

O Aplicativo utiliza serviços de terceiros para funcionamento e melhoria contínua.

Esses serviços podem coletar dados de acordo com suas próprias políticas de privacidade.

---

## 10. ALTERAÇÕES NESTA POLÍTICA

Esta Política pode ser atualizada a qualquer momento.
